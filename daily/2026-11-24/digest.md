# 2026-11-24 — 오늘의 표현

- **anything the user will want to keep belongs somewhere durable** — `belong + 장소` 가 "거기가 제자리". 임시 폴더에 두면 안 되는 것을 가를 때 쓴다.
- **read against the working directory and leads nowhere** — `read A against B` 는 B 를 기준으로 A 를 해석하기. `lead nowhere` 는 링크, 단서, 논의가 성과 없이 끝날 때 두루 쓴다.
- **The user hasn't heard from you in a while** — `hear from` 은 연락을 받다. 부정문에서는 `for a while` 보다 `in a while`.
- **get around these limits** — 제한을 돌아서 피하기. 격식은 `circumvent`, 버그를 피할 때는 `work around`.
- **dropping filler, articles, and pleasantries** — 군말, 관사, 인사치레. 글을 줄이라는 피드백에 그대로 쓸 낱말 셋.
- **a shortcut past the design pass** — `shortcut past` 는 그 단계를 지나쳐 가는 샛길. `shortcut to` 와 전치사가 달라 뜻이 갈린다.
- **it opens with the feedback list** — `open with` 로 시작하고 `close with` 로 닫는다. 가장 중요한 것을 앞에 낼 때는 `lead with`.
