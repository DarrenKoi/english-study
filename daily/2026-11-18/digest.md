# 2026-11-18 — 오늘의 표현

- **One thing to reconcile before merge.** — 병합 전에 맞춰야 할 것 하나. `reconcile` 은 어긋난 두 상태를 맞춘다는 뜻.
- **the branch is red on `npm test` until it is committed** — 실패 사실과 풀리는 조건을 한 문장에. `red on + 검사`, `until` 절.
- **I did not invent a cadence.** — 근거 없는 주기를 지어내지 않았다. `invent` = 꾸며 내다.
- **which I treated as a typo** — 원문을 이렇게 해석했다고 밝히는 관계절. `treat A as B`.
- **Every field name is honoured; nothing diverges.** — 규격을 그대로 지켰다. `honour a contract`.
- **That test exists to force a conversation** — 검사의 목적은 막기가 아니라 논의하게 만들기. `exist to + 동사`.
- **A recommendation is a judgment, not a validation.** — 추천은 판단이지 맞장구가 아니다.
