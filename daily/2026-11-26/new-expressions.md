- 설명: `owe` 는 "빚지다"여서 `be owed` 는 "아직 갚지 않은, 해 줘야 할". 남은 일을 "할 일"이 아니라 "빚"으로 말해 의무라는 무게가 실립니다. `Only` 가 문장 맨 앞에서 주어를 한정해요.
- 예문: The code is merged, so only the release notes are owed.
- 유사어: is still outstanding (격식, 회계 느낌), is left to do (평이), is pending (중립, 기술 문서)
- 반의어: is done, has been delivered
