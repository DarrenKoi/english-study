# 2026-08-28 — 오늘의 표현

1. **it now states the opposite of the code** — 문서가 코드와 정반대를 말하고 있다. `different` 가 아니라 `the opposite` 라 방치 불가 등급이 된다.
2. **was left contradicting it** — 한쪽만 고치고 남겨진 문서의 상태. 파일을 주어로 둬 지적이 사람을 겨누지 않는다.
3. **the compiler catches none of it** — 여섯 군데에 등록해야 하는데 하나도 빌드가 안 잡아 준다. 조용한 실패의 최악형.
4. **It's a deletion, not an addition.** — "일이 늘어난다"는 저항을 첫 줄에서 뒤집는 리팩터링 제안문.
5. **it's wearing the default layout as a costume** — 공용 틀에 속한 척하지만 실은 다 따로 갖고 있다는 비유.
6. **worth deciding deliberately rather than discovering later** — 지금 정하라고 압박하지 않으면서 방치 비용을 알리는 마무리.
7. **a PASS only proves the script ran** — 실패시켜 보지 않은 초록불은 아무것도 증명하지 않는다. `only` 가 증명 범위를 자른다.
