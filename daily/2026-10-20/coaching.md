## 영어 다듬기

### 카드 1 — 로컬 실행 지시
- 내가 쓴 영어: "make sure to run the web application in local host mode (both home and office)."   (출처: transcript:[user] bulk_recipe_copy)
- 정정: `local host` → `localhost`(한 단어 고유명). 문장 첫 글자는 대문자.
- 더 나은 표현: Make sure the web app runs on localhost, both at home and at the office.
- 왜: 괄호 속 `(both home and office)` 는 장소 전치사가 빠져 있다. `at home and at the office` 로 풀면 문장 안에 자연스럽게 들어간다. `in … mode` 는 앱에 그런 모드가 실제로 있을 때만 쓴다.

### 카드 2 — 포트 충돌
- 내가 쓴 영어: "since we have the same ports as used in skewnono_v3_nuxt, we may need to use different ports for python and npm run dev mode"   (출처: transcript:[user] bulk_recipe_copy)
- 정정: `the same ports as used in X` → `the same ports as X` 또는 `the same ports that X uses`. `as used in` 은 과거분사 축약이라 어색하다.
- 더 나은 표현: Since we're using the same ports as skewnono_v3_nuxt, we should switch to different ports for the Python server and `npm run dev`.
- 왜: `may need to` 는 확신이 없는 말투라 지시가 흐려진다. 충돌이 확실하면 `should switch to` 가 낫다. `npm run dev mode` 는 명령어 이름이라 `mode` 를 빼고 코드로 둔다.

### 카드 3 — 지금 보이는 오류
- 내가 쓴 영어: "currently I see 사용자를 확인할 수 없습니다 …"   (출처: transcript:[user] bulk_recipe_copy)
- 더 나은 표현: Right now I'm getting this error: "사용자를 확인할 수 없습니다 …"
- 왜: 화면에 뜬 메시지를 보고할 때는 `I'm getting this error:` 뒤에 따옴표로 인용하면 어디까지가 메시지인지 분명하다. `currently` 는 문두보다 `Right now` 가 구어에서 자연스럽다.

### 카드 4 — 성과 리뷰 요청 첫 문장
- 내가 쓴 영어: "Based on what I did in this year 2026, I have to report "본인 성과 review" to the system and I can recommand my-self to be promoted to the higher ladder."   (출처: transcript:[user] pm_notes)
- 정정: `in this year 2026` → `this year (2026)`(`this year` 앞에는 전치사 불필요). `recommand` → `recommend`. `my-self` → `myself`. `to the higher ladder` → `to the next level`(사다리는 `climb the ladder` 처럼 동사와 쓴다).
- 더 나은 표현: I need to submit my 2026 self-review to the system, and I can nominate myself for promotion to the next level based on this year's work.
- 왜: 사내 자기 추천은 `recommend myself` 보다 `nominate myself` 가 실제로 쓰는 말이다. `I have to report … to the system` 은 `submit … to the system` 이 더 정확하다.

### 카드 5 — 폴더와 파일 만들어 줘
- 내가 쓴 영어: "can you create achivement_review folder and write down what we have done today into md file and html file."   (출처: transcript:[user] pm_notes)
- 정정: 관사 누락 — `an achievement_review folder`, `an md file and an HTML file`. 철자 `achivement` → `achievement`. `write down … into` → `write … up in`.
- 더 나은 표현: Can you create an `achievement_review` folder and write up what we've done this year as both a Markdown and an HTML file?
- 왜: 원문의 `today` 는 실제 의도(올해 성과)와 달라 어시스턴트가 해석을 따로 밝혀야 했다. 기간을 정확히 써 주면 그 단계가 사라진다.

### 카드 6 — 상사 관점에서
- 내가 쓴 영어: "From the boss point of view, I have to write down what I contribute to the company and the coworkers."   (출처: transcript:[user] pm_notes)
- 정정: `the boss point of view` → `my boss's point of view`(명사 수식에는 소유격 `'s` 필요). `what I contribute` → `what I've contributed`(올해 한 일이라 현재완료). `the coworkers` → `my coworkers`.
- 더 나은 표현: It should be written from my boss's point of view, showing what I've contributed to the company and to my coworkers.
- 왜: 원문은 "내가 써야 한다"와 "상사 관점"이 한 문장에 섞여 누구 관점인지 흐리다. 문서의 관점을 주어로 세우면 요청이 분명해진다.

### 카드 7 — 수상 사실 알려 주기
- 내가 쓴 영어: "To note, from align fail tuning case, I got the award "AX Advance 포상" from AI Summit 2026 "AX Innovation Challenge"."   (출처: transcript:[user] pm_notes)
- 정정: `To note,` → `Note that` 또는 `Also,`(`To note` 는 문두 연결어로 쓰지 않는다). `from align fail tuning case` → `for the align-fail tuning case`(관사 + 원인의 `for`). `got the award … from` → `received … at`(행사에서 받으면 `at`).
- 더 나은 표현: Also note that the align-fail tuning work won the "AX Advance" award at the AX Innovation Challenge, AI Summit 2026.
- 왜: 수상 주체를 과제(`the work won`)로 두면 겸손하면서도 성과가 앞에 선다. 자기를 주어로 쓰고 싶다면 `I received the AX Advance award for …`.

### 카드 8 — 한국어로 달라
- 내가 쓴 영어: "give me in Korean."   (출처: transcript:[user] pm_notes)
- 정정: `give` 는 목적어 둘이 필요하다 → `give it to me in Korean` 또는 `give me that in Korean`.
- 더 나은 표현: Can you give me that in Korean?
- 왜: 짧은 요청일수록 `Can you …?` 하나로 공손함이 확 올라간다. `Please switch to Korean.` 도 대화 언어를 바꾸자는 뜻으로 자주 쓴다.
