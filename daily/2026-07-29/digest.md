### 오늘의 정독

이름 바꾸자는 제안을 거절하는 단락을 골랐습니다. `Give the home stand-in a different name and it has to ...` 처럼 명령문을 조건절로 쓴 다음, 대시 뒤 `which` 로 앞 절 전체를 받아 결과 둘을 `and worse` 로 경중까지 매깁니다. 관계대명사를 뺀 접촉절(`the thing the stand-in exists for`, `a path production never takes`)이 문단 처음과 끝에 한 번씩 놓여 수미상관을 만드는 것도 볼 만합니다.

### 오늘의 코칭

- **영어 다듬기 카드 1** — `is existed` 는 늘 틀립니다. exist 는 자동사라 수동태가 없어요(`happen`, `occur`, `belong` 도 같은 무리). `when I pull git` 도 pull 의 목적어가 git 이 아니라서 `when I run git pull` 로 갑니다.
- **영어 다듬기 카드 2** — `you'd better to use` → `you'd better use`(to 없음). 게다가 had better 는 경고 쪽이라 제안 자리에는 셉니다. `Would it be safer to ...?` 로 낮추세요.
