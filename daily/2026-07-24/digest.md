# 2026-07-24 — 오늘의 표현

- **close the loop on X** — 열어 뒀던 확인 건이 검증돼 매듭지어졌다는 뜻. finish 와 달리 "결과가 돌아와 순환이 완성됐다"가 핵심입니다.
- **with room to spare** — 아슬아슬이 아니라 여유 있게 통과했다. 수치 뒤에 붙이는 부사구라 어순 부담이 없습니다.
- **line up with** — 두 근거가 같은 방향을 가리킨다. 상대 말이 맞았다고 부드럽게 인정할 때 씁니다.
- **textbook X** — "딱 그 전형"이라는 진단어. 칭찬이 아니라 분류이고, 뒤에 `But …` 이 자주 따라옵니다.
- **bespoke** — 맞춤 양복에서는 칭찬이지만 코드에서는 뒤집혀 "공용 부품 안 쓰고 혼자 만든"이라는 비판.
- **below the fold** — 스크롤해야 보이는 자리. 접힌 신문 아래쪽에서 온 말이라 `off-screen` 과 다릅니다.
- **build to a quality floor** — 자랑거리가 아니라 못 지키면 결함인 최저선. floor(하한) ↔ ceiling(상한).

### 오늘의 정독

단락 1은 BM/PM 어댑터 계획서인데, 두 인덱스에 붙인 괄호 설명 `(work that happened)` / `(work that is scheduled)` 가 시제만으로 두 데이터의 존재 이유를 갈라 놓습니다. 경고 문장의 `places markers nowhere instead of failing` 도 함께 보세요 — "증상이 없다는 게 증상"을 `instead of` 하나로 접었습니다. → [reading.md](reading.md)

### 오늘의 코칭

- 영어 다듬기: `the code what we have done` → `the code we wrote`. `what` 은 선행사를 이미 품고 있어 앞에 명사를 둘 수 없습니다. 명사가 있으면 `that`(생략 가능).
- 영어 다듬기: `the connection with api is no problem` → `there's no problem with the API connection`. `X is no problem` 은 "그건 어렵지 않아요"라는 수락 표현이라 뜻이 어긋납니다.
- 영어 다듬기: `have you set the chat models … in office?` → `at the office`. 관사 없는 `in office` 는 "재임 중인"이라는 딴 뜻입니다.
- 영어 다듬기: `push to the main` → `push to main`. 브랜치 이름은 고유명사라 관사를 붙이지 않습니다.
