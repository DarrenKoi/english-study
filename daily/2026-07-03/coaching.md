## 한글→영어

### 카드 1 — 세션 정리 지시   (내가 쓴 한글)
- 내가 쓴 한글: "이번 대화에서 진행한 작업을 정리하여 저널 디렉토리에 마크다운 파일로 저장해."   (출처: transcript:[user] 저널 요청)
- 자연스러운 영어: Summarize what we did in this session and save it as a markdown file in the journal directory.
- 왜 이렇게: "정리하여 ~ 저장해"는 목적어(작업 요약)를 만든 뒤 저장하는 두 동작이므로 `Summarize ... and save it as ...`로 두 동사를 `and`로 잇는 게 가장 자연스럽습니다. "마크다운 파일로 저장"은 **결과 형태**를 나타내는 `save it as a markdown file`(전치사 `as` = ~의 형태로); `save it to a markdown file`도 되지만 `as`가 "파일 형식"까지 담아 더 정확합니다. "저널 디렉토리에"는 위치라서 `in the journal directory`.

## 영어 다듬기

### 카드 1 — 다음 할 일 묻기
- 내가 쓴 영어: "what's next thing to do? based on the superpowers and journals"   (출처: transcript:[user])
- 정정: `what's next thing` → `what's **the** next thing` — 최상급·서수(next)에는 정관사 `the`가 필요합니다. 문두 대문자와 물음표 위치도 정리.
- 더 나은 표현: What should I tackle next, based on the superpowers docs and the journals?
- 왜: `the next thing to do`도 맞지만, 사람이 주어인 `What should I tackle next?`가 더 능동적이고 자연스럽습니다. `based on ...`은 앞 절 전체에 걸리는 부사구라 쉼표로 이어 붙이면 깔끔합니다.

### 카드 2 — 조건 확인 질문
- 내가 쓴 영어: "in eframe, if it fine that some msr folders contain only S-images?"   (출처: transcript:[user])
- 정정: `if it fine` → `**is it** fine` — 의문문이므로 be동사를 살려 주어 앞에 도치해야 합니다(`if`는 "~라면"이라 여기선 오답). `in eframe` → `in the eframe dataset`(관사 + 무엇의 eframe인지 명시).
- 더 나은 표현: In the eframe dataset, is it OK for some msr folders to contain only S-images?
- 왜: "~해도 괜찮냐"는 `is it OK/fine for X to do Y?`(for + 의미상 주어 + to부정사) 패턴이 가장 관용적입니다. `is it fine that ...`(that절)도 되지만 `for ... to ...`가 더 매끄럽고 격식·구어 모두에서 안전합니다.

### 카드 3 — 결론에 동의 구하기
- 내가 쓴 영어: "No need further test as we are almost sured to say that image from rcp is not strong enough to get the right align point when align failture happens. agree or disagree?"   (출처: transcript:[user])
- 정정: `No need further test` → `No need **for** further **testing**`(need for + 명사; test는 불가산 활동일 땐 testing) · `almost sured` → `almost **sure**`(sure는 형용사, 과거분사형 없음) · `image from rcp` → `**the** image from **the** rcp` · `failture` → `**failure**` · 문장 끝 `align failture happens` → `alignment fails`.
- 더 나은 표현: No need for further testing — I'm fairly confident the rcp image isn't distinctive enough to localize the correct align point when alignment fails. Agree or disagree?
- 왜: `almost sure to say`는 "말할 뻔했다"는 엉뚱한 뜻이 될 수 있어, "꽤 확신한다"는 `I'm fairly confident (that) ...`로 바꿉니다. `get the right point`보다 도메인 동사 `localize`가 한 단계 위 표현이고, `when align failure happens`는 절 `when alignment fails`로 줄이면 훨씬 자연스럽습니다.

### 카드 4 — 대안 제안하며 근거 대기
- 내가 쓴 영어: "what is worth of trying heatmap? since we have been trying with RRF and haven't yet gottn good result. why not trying heatmap?"   (출처: transcript:[user])
- 정정: `what is worth of trying` → `what **is the value of** trying` (또는 `what's worth trying about`; `worth of`는 비문) · `gottn` → `**gotten**` · `haven't yet gotten good result` → `... good **results**`(가산 복수) · `why not trying` → `why not **try**`(why not + 동사원형).
- 더 나은 표현: What's the upside of trying the heatmap approach? We've been going with RRF and haven't gotten good results yet — so why not give heatmap a shot?
- 왜: "~할 가치가 뭐냐"는 `What's the value/upside of doing X?`가 정석입니다. `why not + 동사원형`은 제안의 고정 형태(`why not try`), `why not trying`은 틀립니다. `give X a shot`(한번 시도해 보다)은 제안을 부드럽게 만드는 구어 관용구예요.
