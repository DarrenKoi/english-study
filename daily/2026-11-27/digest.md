# 2026-11-27 — 오늘의 표현

- **Spin up a background agent to do the research** — `spin up` 은 서버, 에이전트, 팀을 금방 띄우기. 뒤의 `so you keep working while it reads` 까지가 위임 한 문장의 본입니다.
- **Follow every claim back to the source that owns it** — 주장을 원출처까지 거슬러 확인하기. `own` 은 소유가 아니라 "그 내용을 책임지는"이에요.
- **match the existing convention, and if there is none, put it somewhere sensible and say where** — 규칙이 있을 때, 없을 때, 보고. 일을 맡길 때 그대로 쓸 세 토막.
- **Such an agent cannot grant escalation** — `grant` 는 권한을 내주는 동사, `escalation` 은 권한 상승. 누가 허가할 수 있는지 선을 긋는 말.
- **The hook will block stopping until the condition holds** — `hold` 가 자동사로 "성립하다". `until` 절은 미래 일이어도 현재형입니다.
- **It auto-clears once the condition is met** — `auto-` + 동사로 "저절로 ~된다". `once` 는 "그 시점을 지나면 바로".
- **one customer, many capabilities / one capability, many customers** — 두 단어의 자리만 바꿔 현장 조직과 제품 조직을 대비하는 구호.
