## 단락 3

A filename looks like `#261007#073000#…#NA#.csv`. It contains `#`, so it **MUST be percent-encoded** in the URL path (`%23`), **otherwise** the HTTP client drops everything after it as a fragment. State this in the group description with the Python one-liner `urllib.parse.quote(filename, safe="")`, and write every `example.path` with the encoded literal (e.g. `/afm/files/%23261007…%23NA%23.csv`) so both the curl and the Python snippet generated by `frontend/app/utils/apiSnippets.ts` **work as pasted**. Read that file to see how `path`, `query`, `read`, `timeout` become snippets. The `afm` blueprint is exempt from the 50 req / 5 s rate limit (`_EXEMPT_BLUEPRINTS` in `backend/__init__.py`); mention it in the group description **only if you confirm it there**. Mention in the group description that the tips / usage / recipes pages are computed in the browser from `/api/afm/files` rows, so a script gets the same inputs from that one call (confirm by reading `frontend/app/pages/afm/[tool]/tips.vue` etc. that they call no other endpoint; **drop the sentence if false**).

**문법·구조**: 사실을 말하는 평서문과 그 사실로 무엇을 할지 시키는 명령문이 번갈아 온다. 첫 문장의 `looks like` 는 "이렇게 생겼다"로 예시를 내놓는 가장 쉬운 틀. 둘째 문장은 `so` 와 `otherwise` 두 연결어로 이유, 의무, 어겼을 때의 결과를 한 줄에 세웠다. 대문자 `MUST` 는 명세 문서의 관습이고 `be percent-encoded` 는 조동사 뒤의 수동이다. `drops everything after it as a fragment` 의 `it` 은 `#` 을 받는다. 셋째 문장은 명령문 둘(`State …, and write …`)에 목적의 `so` 절이 붙었다. 여기서 `so` 는 `so that` 의 줄임이라 둘째 문장의 `so`(그래서)와 뜻이 다르다. 넷째 문장의 `that file` 은 바로 앞의 `apiSnippets.ts` 를 받고 `to see how … become snippets` 는 목적을 나타내는 to 부정사 안에 간접의문문이 들어간 꼴. 다섯째 문장은 세미콜론 앞이 사실, 뒤가 조건부 지시이고 `only if` 가 조건을 좁힌다. 마지막 문장은 `Mention … that …, so …` 로 쓸 내용과 그 내용의 쓸모를 함께 주고, 괄호 안에서 확인 방법(`confirm by reading …`)과 틀렸을 때의 처리(`drop the sentence if false`)를 덧붙인다. `are computed` 는 수동태로, 계산하는 주체보다 계산이 어디서 일어나는지(`in the browser`)를 앞세운다.

**핵심 표현**: `it MUST be percent-encoded …, otherwise …` — 의무와 어겼을 때의 결과를 한 문장에. / `work as pasted` — 예제는 붙여 넣은 그대로 돌아야 한다는 기준. / `only if you confirm it there` 와 `drop the sentence if false` — 전달한 사실을 맡은 쪽이 다시 확인하게 하는 조건.

**격식 짝**: (작성)
- refined: Because the filename contains `#`, it must be percent-encoded before being placed in the URL path; otherwise the client will discard the remainder as a fragment.
- plain: The filename has a `#` in it, so encode it first. If you don't, everything after the `#` just gets cut off.
