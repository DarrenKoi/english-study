## 영어 다듬기

### 카드 1 — 사무실 agent 에게 편지를 써
- 내가 쓴 영어: "if you need info about slot, write down the letter to the office agent. he will answer for it"   (출처: transcript:[user] skewnono-v3-nuxt)
- 정정: `write down the letter` → `write a letter`. `write down` 은 들은 것을 받아 적는다는 뜻이고, 아직 없는 편지라 `the` 가 아니라 `a` 다. `answer for it` → `answer it`. `answer for` 는 "~의 책임을 지다"라는 다른 숙어다. `about slot` → `about the slot`(단수 가산명사).
- 더 나은 표현: If you need to know more about the slot, write to the office agent. It'll get back to you.
- 왜: `write to + 사람` 만으로 "편지를 쓰다"가 된다. 답이 나중에 온다는 느낌은 `get back to you` 가 준다. agent 는 `it` 으로 받는 편이 무난하다. 질문을 편지에 담으라는 뜻을 세우려면 `put the question in a letter to the office agent`.

### 카드 2 — 구분되게 스타일을 주자
- 내가 쓴 영어: "afm, the recent measurement and 검색 결과, We can give some effect on the recipe name, Lot id, slot id so that we can differentiate them."   (출처: transcript:[user] skewnono-v3-nuxt)
- 정정: `give some effect on` 은 영어에 없는 결합이다. 꾸밈을 준다는 뜻은 `style … differently` 나 `add some visual distinction to`. `the recent measurement` 는 목록이라 복수 `recent measurements`. 문장 가운데의 `We` 는 소문자로.
- 더 나은 표현: On the AFM page, in the recent-measurements and search-results lists, could we style the recipe name, lot ID and slot ID differently so they're easy to tell apart?
- 왜: `effect` 는 결과나 영상 효과를 말하고 "서로 다르게 보이게 한다"는 뜻은 없다. `differentiate` 는 맞는 단어지만 말로는 `tell apart` 가 훨씬 흔하다. 맨 앞의 `afm, …,` 나열은 `On the AFM page, in the … lists,` 로 전치사를 붙여야 위치 정보가 된다. 어시스턴트는 답에서 같은 뜻을 `give each identifier its own form` 과 `stay distinguishable at a glance` 로 적었다.
