## "follows on from"
- 레지스터: professional
- 출처: transcript:skewnono-v3-nuxt (Slot 질문서 보고)
- 맥락: 새 문서나 질문이 앞선 것의 후속임을 밝힐 때(보고·메일, 영국식 색이 약간 있는 중립 문어).
- 한국어: ~에 이어지는 것이다
- 설명: `follow on from X` 는 "X 다음에 자연스럽게 이어지다". `follow` 만 쓰면 순서가 뒤라는 말이고, `on from` 이 붙으면 내용이 이어진다는 뜻이 선다. 원문은 뒤에 `, which hasn't been answered yet` 를 붙여 앞 질문의 상태까지 한 문장에 담았다.
- 예문: This follows on from Q16 in questionnaire 3, which hasn't been answered yet.
- 유사어: is a follow-up to X (가장 흔한 말), builds on X (앞의 것을 토대로 더 나아갈 때), picks up where X left off (구어)
- 반의어: stands on its own (앞의 것과 무관하게 독립적이다)

## "acts as if it were"
- 레지스터: technical, professional
- 출처: transcript:skewnono-v3-nuxt (flex 레이아웃 Insight)
- 맥락: 설정값이 겉보기와 다르게 다른 값처럼 동작한다고 설명할 때(기술 설명).
- 한국어: 마치 ~인 것처럼 동작한다
- 설명: `as if` 뒤에 `were` 를 쓰면 가정법이다. 실제로는 그 값이 아니라는 말. 주어가 단수 `a percentage basis` 여도 `was` 대신 `were` 를 쓰는 편이 격식에 맞다. 원문은 `When the parent has no fixed height` 로 조건을 먼저 걸었다.
- 예문: When the parent has no fixed height, a percentage basis acts as if it were "fit the content".
- 유사어: behaves like (평이), is treated as (엔진이 그렇게 취급한다는 쪽), effectively becomes (결과로 말하기)

- 설명: `of one's own` 은 "자기 몫의, 독자적인". `no height of their own` 은 높이가 있긴 한데 다른 데서 빌려 온다는 뜻을 품는다. 뒤의 `so the row is exactly as tall as the chart` 가 그 결과.

- 설명: `명사 + worth + -ing` 로 뒤에서 꾸민다. 관계사와 be 동사(`that are`)가 빠진 꼴이다. 어제 `nothing worth fixing` 과 같은 뼈대. 원문 문장은 `makes that loop produce tests worth keeping` 으로, `make + 목적어 + 동사원형` 안에 들어 있다.
- 예문: This skill is the reference that makes that loop produce tests worth keeping.
- 유사어: tests that earn their place (비유), tests that pull their weight (구어), tests of lasting value (격식)
- 반의어: throwaway tests (버릴 테스트)

## "agreeing the seams up front"
- 레지스터: professional
- 출처: transcript:skewnono-v3-nuxt (tdd 스킬 문서)
- 맥락: 일을 시작하기 전에 범위를 미리 합의해 두자고 할 때(프로세스 문서, 회의).
- 한국어: 경계를 미리 합의해 두는 것
- 설명: `up front` 는 "시작하기 전에 미리". `agree` 를 타동사로 쓰는 것은 영국식이고, 미국식은 `agree on the seams`. 동명사구 전체가 주어가 되어 `is how testing effort lands on …` 으로 이어진다. `land on` 은 노력이 어디에 떨어지는지를 말한다.
- 예문: You can't test everything — agreeing the seams up front is how testing effort lands on the critical paths and complex logic instead of every edge case.
- 유사어: settling the scope in advance (격식), deciding it before you start (평이), getting aligned early (회의 구어)
- 반의어: figuring it out as you go (하면서 정하기)

## "the tests go insensitive to real changes"
- 레지스터: technical
- 출처: transcript:skewnono-v3-nuxt (tdd 스킬 문서)
- 맥락: 테스트가 실제 변화를 못 잡게 된다고 경고할 때(테스트 설계).
- 한국어: 테스트가 실제 변경에 둔감해진다
- 설명: `go + 형용사` 는 나쁜 쪽으로 변한다는 말이다(`go stale`, `go quiet`, `go wrong`). `become` 보다 구어답고 "모르는 새 그렇게 됐다"는 느낌이 붙는다. `insensitive to` 는 "~에 반응하지 않는".
- 예문: When you write all the tests first, the tests go insensitive to real changes.
- 유사어: stop catching real changes (평이), become blind to regressions (비유), lose their signal (구어)
- 반의어: fail when behavior actually changes (동작이 바뀌면 실패한다)
