# 2026-08-10 — 오늘의 표현

- **treat every ID as an opaque string** — 값의 속을 파싱하지 말고 그대로 넘겨라. 접미사가 의미 있어 보여도 근거로 삼지 않는다는 경고.
- **the installed binary is the authority for command syntax** — 문서가 아니라 실물이 기준이다. `X is the authority for Y` 틀을 통째로 외워 두면 좋다.
- **tee up a concrete restart** — 대신 해 주지 않고, 곧바로 착수할 수 있게 올려만 둔다. 인수인계 문서의 태도를 한 구절로 압축한다.
- **momentum is cheapest there** — "거기서 다시 속도 붙이는 비용이 제일 싸다". 여러 후보 중 하나를 고른 이유를 최상급 하나로 끝낸다.
- **dense is better than verbose** — `dense` 를 칭찬으로 쓰는 게 요점. 정보 밀도가 높다는 뜻이지 읽기 어렵다는 뜻이 아니다.
- **report findings ranked by severity** — 리뷰 의뢰문의 표준 문구. 과거분사 `ranked by X` 로 정렬 기준을 뒤에 붙인다.
- **a thin forwarder only** — 받아서 그대로 넘기기만 하는 얇은 중계자. 끝의 `only` 가 "그 이상 하지 마라"까지 얹는다.

### 오늘의 코칭

- 한글→영어: "지금 시점에서 적용 가능한 것들 적용해보자" → `Let's apply whatever we can land right now` — "적용 가능한"을 형용사로 번역하지 말고 `what we can land` 처럼 동사로 풀기.
- 한글→영어(고급): "측정 대상이 측정을 오염시킵니다" → `the thing being measured corrupts the measurement` — 진행 수동 `being measured` 로 "지금 재고 있는 그것"이라는 관계를 살립니다.
- 영어 다듬기: `how can we give a pane name?` → `How do we name a pane?` — 방법을 물을 땐 `can we` 보다 `How do we …?`, 그리고 도구가 쓰는 용어(`label`)를 그대로 쓰면 답이 정확해집니다.
- 영어 다듬기: `what benefits can we expect from ftp handler improvement?` → `What do we actually get out of the ftp_handler work?` — 제안서 문체를 구어체로 낮추고 `actually` 로 "홍보 말고 실제로"를 얹습니다.
