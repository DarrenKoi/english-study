# 2026-07-16 — 오늘의 표현

오늘 배치는 `skewnono_v3_nuxt` 설계 문서(영문)가 주를 이뤄, 실무 영어 표현과 정독 단락이 풍성했습니다.

- **thin glue** — 자체 로직 없이 두 모듈을 잇기만 하는 얇은 코드. *It is thin glue: it reads the IDs and calls the gather function.*
- **kick off (a background job)** — (작업·프로세스를) 개시하다. *The endpoint kicks off a fleet download in the background.*
- **circuit breaker** — 반복 실패하는 호출을 잠시 끊어 장애 확산을 막는 안정성 패턴.
- **relay (X to the frontend)** — 저장하지 않고 받아서 곧바로 중계·전달하다.
- **surface as (a JSON error)** — 내부 실패가 (…의 형태로) 겉으로 드러나다. *Office failure surfaces as JSON, never a fabricated image.*
- **invent data** — 실측 안 한 값을 보간·추정으로 지어내다(계측 도구에서 금기).
- **on demand** — 미리가 아니라 필요할 때 그때그때. *It fetches the data on demand.*

전체 표현 해설 → `new-expressions.md` (총 14개, 유사어·반의어 포함).
