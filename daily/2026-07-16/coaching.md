## 한글→영어

### 카드 1 — "더 자세히 알고 싶다"   (내가 쓴 한글)
- 내가 쓴 한글: "of, for의 사용법 좀 더 자세히 알고 싶어."   (출처: spool:spool/궁금한점.txt)
- 자연스러운 영어: I'd like to understand how *of* and *for* are used, in a bit more detail.
- 왜 이렇게: "사용법"을 how ~ are used 로 풀면 자연스럽습니다("the usage of"는 딱딱). "좀 더 자세히"는 문장 끝에 **in (a bit) more detail** 로 얹는 게 가장 관용적이에요. 회화체로 더 가볍게는 *Can you break down how to use "of" vs "for"?* (break down = 조목조목 풀어 주다). "알고 싶어"는 want 보다 **I'd like to / I want to get a better sense of** 가 공손합니다.

### 카드 2 — "왜 X가 되는 거지?"   (내가 쓴 한글)
- 내가 쓴 한글: "왜 study는 가산명사가 되는거지."   (출처: spool:spool/궁금한점.txt)
- 자연스러운 영어: Why does *study* count as a countable noun?
- 왜 이렇게: "왜 ~가 되는 거지"의 "되다"를 그대로 become 으로 옮기면 어색합니다. 상태/분류를 물을 땐 **count as / qualify as / behave as**(…로 취급되다/분류되다)가 자연스러워요: *Why does "study" count as countable (but "research" doesn't)?* 혼잣말 같은 "~거지"의 뉘앙스는 문장 앞에 *I wonder* 를 붙여 *I wonder why "study" is countable.* 로 살릴 수 있습니다.

### 카드 3 — "이거 이렇게 안 쓰나?" (관용적 확인 질문)   (내가 쓴 한글)
- 내가 쓴 한글: "Sun, Moon 이런 대문자를 사용하지 않나?"   (출처: spool:spool/궁금한점.txt)
- 자연스러운 영어: Don't we capitalize these — like *Sun* and *Moon*?
- 왜 이렇게: "대문자를 사용하다"는 한 단어 동사 **capitalize** 로 끝냅니다("use a capital letter"보다 훨씬 자연). "~하지 않나?"처럼 **본인 생각을 확인**하는 뉘앙스는 부정 의문문 *Don't we ~?* / *Shouldn't it be ~?* 가 딱이에요. 예를 들 때 대시(—) 뒤에 *like Sun and Moon* 을 붙이면 구어에서 자연스럽게 이어집니다.
