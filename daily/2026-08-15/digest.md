# 2026-08-15 — 오늘의 표현

- **root and branch** — 뿌리째, 남김없이. `X is gone, root and branch.` 처럼 삭제 선언 뒤에 붙여 "부분 제거가 아니다"를 못 박는다.
- **first writer wins** — 먼저 쓴 쪽이 이긴다. `setdefault` 계열 우선순위를 한 줄로 정의하는 규칙 표현이고, 짝인 `last writer wins` 와 반드시 구분해서 쓴다.
- **it looked worse than it was** — 보기보다는 별일 아니었다. 상대가 이미 경고 화면을 본 상황에서 보고를 여는 첫 문장.
- **stale but harmless** — 낡았지만 해롭지 않다. 발견은 숨기지 않으면서 우선순위만 낮추는 짧은 판정구.
- **isolate exactly one variable** — 변수를 딱 하나만 남기다. 실험 설계 어휘가 그대로 디버깅 대화로 넘어온 사례.
- **in favor of** — 버린 쪽이 목적어, 남긴 쪽이 뒤. 어순이 고정이라 뒤집으면 뜻이 반대가 된다.
- **take effect** — 발효되다. `only takes effect once it's pushed` 처럼 조건절을 달아 "아직은 아니다"까지 함께 전달한다.

### 오늘의 코칭
- 한글→영어: "초기화 됩니다. 스크롤 안됩니다." → `It resets. It doesn't scroll.` — `is reset` 으로 수동태를 만들면 없던 행위자가 끌려 들어온다. ([카드 1](coaching.md))
- 영어 다듬기: `make sure X to be used` → `make sure X is used`, `I ask him do the job` → `I'll have him run the job` — `make sure` 뒤 that절, `ask + 목적어 + to부정사`, 그리고 사역 `have`. ([카드 7](coaching.md), [카드 12](coaching.md))
