# 2026-11-22 — 오늘의 표현

- **The user chose brevity over narration.** — `choose A over B` 는 B 를 두고 A 를 고른다는 말. `instead of` 보다 짧고, 저울질한 끝에 골랐다는 어감이 있다.
- **Never trade correctness for brevity** — `trade A for B` 는 A 를 내주고 B 를 얻는 것. 내주는 쪽이 먼저 온다.
- **Conciseness never means withholding requested information.** — `X never means doing Y` 로 규칙의 오해를 미리 막는다. `withhold` 는 줄 수 있는데 안 주는 것.
- **…, these rules win.** / **take precedence over** — 같은 뜻의 구어와 문어. 충돌 조건은 `Where … conflict with …` 로 연다.
- **`WorkflowRunner` is not to be given routing** — `is not to be + p.p.` 는 이미 내려진 결정을 알리는 금지. `must not` 보다 덜 명령조.
- **deliberately omits `eqp_id` so it can't be re-added** — 빠진 것이 실수가 아니라 설계임을 남기는 문장. `so (that)` 이 목적을 단다.
- **otherwise … rcp/msr appear absent** — 없는 것이 아니라 없어 보인다. `appear + 형용사` 가 증상과 실제를 가른다.
