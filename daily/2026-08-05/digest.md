### 오늘의 코칭

- **한글→영어**: "지금 상태에서는 Redis가 사 주는 게 없습니다" → `As things stand, Redis buys us nothing.`
  "사 주다" 은유가 영어 buy 와 그대로 겹친다.
- **영어 다듬기**: "Have we filter the lot_cd…?" → `Didn't we already filter lot_cds…?`
  현재완료는 have + 과거분사, 확인 질문은 Didn't we already 가 관용.
- **영어 다듬기**: "increase the popup window size in both ways" → `make the popup bigger in both dimensions.`
  in both ways 는 "두 가지 방법"으로 읽힌다 — 크기의 축은 dimensions.
