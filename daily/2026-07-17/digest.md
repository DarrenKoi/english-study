# 2026-07-17 — 오늘의 표현

오늘 소재는 전부 프로젝트 설계·계획 문서(영어)였습니다. 엔지니어링 글에서 자주 나오는 "설계 근거" 어휘가 많습니다.

- **read as (visually) identical / distinct** — (결과적으로) ~처럼 보이다/읽히다. 사물이 주어. *They read as visually identical.*
- **opt out (of X)** — 기본은 켜져 있고 특정 대상만 명시적으로 빠지다. `unless explicitly opted out`.
- **bake in** — 빼낼 수 없게 굽듯이 고정해 넣다. *bake in a solid background.*
- **an acceptable trade-off** — 단점을 알지만 감수할 만한 절충. 설계 결정 상용구.
- **funnel through (a single X)** — 여러 경로를 하나의 통로로 모아 한곳에서 통제하다.
- **a single source of truth** — 정의가 한 곳에만 있어 그것이 유일한 기준(SSOT).
- **retain source order** — 동순위는 원래 순서를 유지 = 안정 정렬(stable sort).
